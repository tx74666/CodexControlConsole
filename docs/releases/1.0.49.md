# 1.0.49 — 手机想法完整带到电脑

手机保存的单条想法可带到已配对电脑：传送前冻结准确版本的标题、正文、执行稿、长期要点、归档状态及所选图片。电脑保存后返回对应条目与工作记录的实际回执，手机原副本继续保留。

- 携带实际图片文件及大小、类型、SHA256；电脑核对收到的字节，不用缩略图、文件名或图片数量代替原图。正文与执行稿分别保存，保留手机来源、想法标识及版本。
- 回执核对本次请求、来源版本、电脑条目和关联记录；打开电脑页面或开始传送不表示保存成功。
- 上次结果未知时保留冻结内容、原交接编号及手机副本，只核对已有结果，不再次传送，也不跳过旧版本发送新版。
- 电脑已有修改、同一手机版本内容不同或版本落后时保留两边，提示核对合并，不自动覆盖电脑内容。
- 浏览器交接不可用时可导出完整 `.console-idea` 备用包，包含冻结文字、执行稿、来源版本、图片清单及实际图片字节；导入仍检查完整内容和图片 SHA256，不能把文字清单当完整备份。

带到电脑和导入备用包都只保存内容，不自动发送 Chat、不执行 Work。准备好以后，用户另行确认讨论，或核对执行稿、真实工作区和允许范围后交给 Codex。

当前限制：普通 Chat 的常驻即时转发桥尚未接通，极速／高／Pro 的实际切换尚未核实；保存成功不代表模型已回答。iPhone 真机的交接标签页、键盘、后台恢复和文件导入未在本轮实测。

已验证：390×844 隔离浏览器中，保存的正文、实际原图和独立执行稿成功带到同一电脑想法；再次带同版本只核对原回执，仍是一份想法和一份导入凭据，原图 SHA256 相等。已配对页面的文件选择、完整包导入和独立执行稿也通过实际操作；该包为明确合成的验收文件。

验证边界：隔离服务只为本轮测试替换固定公开 origin，没有使用生产数据库。公开页面已生成包含原图的包，但内置浏览器两次未返回实际下载凭据，不能称手机导出／下载／导入整条链路已验收。iPhone 真机仍未验证。正式发布及安装另按真实 CI、资产校验、原安装身份、数据库、草稿、图片、互传、音乐与设置保留证据核对。
