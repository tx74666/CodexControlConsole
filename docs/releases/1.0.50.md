# 1.0.50 — 原图继续讨论与想法整理

继续讨论已保存想法时，可以从“已保存图片”明确选取本次图片。开始讨论不会自动把原图全部带入；图片草稿保留讨论身份、想法版本与原文件校验，避免在切换想法后误用。

想法详情的“更多”新增移动到已有项目、拆分选中文字和合并另一条想法。拆分复制保存正文的准确字符范围；合并生成第三份，两份原稿继续保留。新内容保留来源快照，长期要点的建议与已确认决定仍分别保存。

手机本地保存和已配对电脑入口采用相同行为。图片上传、来源冲突、重复请求、中文与表情拆分及原图保留均通过隔离检查。普通 ChatGPT 的持续自动转发与极速／高／Pro 实际档位仍待接通核实；本次更新不将保存或入队宣称为实际回答。
