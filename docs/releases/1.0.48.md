# 1.0.48 — 手机对话与想法管理

手机默认进入对话：首页保留输入、发送、只保存、极速／高／Pro 与想法入口。想法使用独立列表和详情，原工作区、互传、音乐、资料从更多进入。

- 只保存文字或图片不触发模型；在已有想法中追加到原条目，保留版本和来源。
- 草稿可恢复；清空创建新讨论身份，保存的想法与图片保留。旧讨论的回答和迟到页面请求不能覆盖新讨论。
- 长期要点区分待确认建议与用户决定，可编辑、删除；执行稿独立保存，交 Codex 时带入真实 Work 审核，不使用旧正文冒充本轮要求。
- 中文输入、图片保存失败、重复请求和列表返回位置有隔离行为测试；讨论及详情撤下固定模块底栏。

当前限制：普通 Chat 的常驻事件转发器尚未接通，实际三档切换未核实；界面显示真实状态，不把入队当作回答。公开手机 App 的本机想法／图片／执行稿尚未自动转到电脑，连接电脑后使用同一电脑资料库。iPhone 真机键盘、麦克风及后台行为未在本轮实测。

验收：实际运行的候选界面完成只保存、清空后找回、独立列表和详情检查；完整轻量质量检查及新增讨论、图片、幂等与 Work 审核测试通过。安装结果和资料保留由本轮正式更新后单独核实，发布本身不表示本机已经更新。
