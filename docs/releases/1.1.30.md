# 1.1.30

Includes the conversation search, stable message rendering, draft reload verification, preference resilience, intended default volume, Transfer schema cache and atomic wallpaper saves prepared in 1.1.29.

The local acceptance of 1.1.29 exposed an older music-state issue: hiding or reloading a page that had not loaded Music could submit an empty selected track. The original failed preservation receipt is retained.

- Idle pages no longer submit music snapshots on hide or unload. Successful saves clear only their own pending state; an older acknowledgement cannot clear a newer edit.
- The backend preserves a saved selection when an empty snapshot arrives while its permitted audio file still exists or its status cannot be verified. Clearing remains available after a normal track deletion proves the file is missing.
- Unchanged music snapshots no longer rewrite the main state or rotate its previous-state backup.

Regression fixtures cover idle pages, pending edits, failed saves, overlapping acknowledgements, old empty snapshots, missing tracks and inaccessible paths. Local installation, preservation checks, selection recovery and live acceptance have separate receipts.
