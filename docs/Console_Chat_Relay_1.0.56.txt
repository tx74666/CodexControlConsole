Codex Console 1.0.56 · Chrome／Edge 普通 Chat 接通说明（2026-10-05）

本版源码允许保存真实 Chrome 或 Edge 的 CUA 页面契约，并由扩展自身浏览器标识核对实际身份，不把 Edge 写成 Chrome。当前已通过官方 CUA 连接观察 Edge 的 Instant 控件；中文原文“思考强度Instant”仍必须同时具有 none 属性。一次已授权的“你好”网页校准已获得真实回答，完成状态原文为“回答已完成”，回执保留原文。这只是网页校准证据，不能替代正式安装或常驻回答回传验收。

两种扩展用途不同。官方 ChatGPT 浏览器扩展用于受支持的 CUA 页面核对；Console 自有扩展负责接收本机已确认的问题并回传回答。安装官方扩展、登录 ChatGPT、注册本机接收端，均不能单独证明 Console 已接通。

真人在 Edge 打开 edge://extensions（Chrome 为 chrome://extensions），开启开发者模式，选择“加载解压缩的扩展”，指向正式安装目录中的 _internal\extensions。该目录应直接包含 manifest.json；“打包扩展”不是加载。安装、权限和重载按钮由真人操作。同一浏览器需已登录 ChatGPT。Console 扩展默认停用，启用灰色时应核对配置，不能靠删除账本或反复发送解决。

接通按两层完成：本机注册工具先核对正式包、固定扩展身份及两种注册表视图，并备份原值，只注册接收端；配置工具再接收已核对的真实 Chrome／Edge CUA 契约，沿用真人原始授权时间，备份并保持私有 SQLite 设置与批准文件一致。配置工具不操作浏览器、不启动转发、不发送问题；JSON 自报 source=cua 不是现场验收。正式 runtime 与接收端须发布、更新并确认实际运行 1.0.56 后，新的 Edge 支持才生效。文件版本变更不代表本机已更新。

启用前核对在途请求及旧队列归属。验收只发送本次明确确认的一条“你好”，观察普通新 Chat 中准确冻结的原问题、真实回答和结束证据，再确认回答回到同一任务 Output。同一确认只发送一次；送达不明保留核对，不自动重发。扩展和原生端连接成功仍不是这轮验收通过。

当前转发仅支持纯文字及实际 Instant 的极速档位；高／Pro未支持，不降档发送。Instant UI 标签不证明底层模型或推理能力。本次回答结束较快，生成中的停止控件仍未取得现场证据，完整页面契约尚未批准，不能用推测选择器补齐。图片、Work常驻往返与iPhone实机表现另行验收。真实回答尚未准确回到原Output时，状态必须继续记录为未接通／待验收；不恢复定期heartbeat，不调用模型API。
