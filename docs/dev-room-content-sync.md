# Dev Room 内容同步

游戏负责展示元素的数量、顺序、类型和布局。Console 读取同一批元素，只修改已有位置的标题、正文、图片和图片说明。新增、删除或重新排列展示元素，在游戏里完成。

「图文／无图片」只改变浏览方式，并记住选择。切换为无图片不会删除图片、说明或编辑草稿。图片支持 PNG、JPEG，每张不超过 10 MB。

编辑后点击「保存」，将文字、图片替换和说明保存在当前资料库。上传图片、保存到 Console 和写入游戏是三个不同的步骤。未保存草稿会保留在原文档；替换图片可随草稿恢复。「保存文字副本」复制文字和图片说明，原图片与替换图片仍保留在原文档的草稿中。

「从游戏更新」先显示更新预览。保存当前语言的草稿后，再确认导入。总案中的托管导航由游戏目录生成，Console 仅按当前语言显示已有文档名称。

向游戏写回时，先在 Unity 编辑器选择 **Tools → RandomRealm → Dev Room → Enable Console Content Bridge (15 Minutes)**，开启本次 15 分钟同步窗口，再点击 Console 的「同步当前文档到游戏」。每次只提交当前已保存的文档，游戏会再次核对来源、版本和未保存状态。

提交后点击「查看同步结果」。只有游戏的真实完成回执才表示同步完成。结果不明确时保留同一个请求，继续核对，不重复提交。同步入口默认折叠，不在空闲时自动派发任务。
