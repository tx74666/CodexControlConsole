# Dev Room 内容功能

本轮保留编辑、图片浏览和同步功能框架。展示类型与模板仍可能调整，当前图文内容尚未连接；不搬入或写回正在运行的 Project Nexus 内容，也不填充正式项目资料。

已有本地历史文档继续保留，可正常阅读和保存。「图文／无图片」记住浏览选择，切换不会删除图片记录或草稿。图片不显示说明，也没有说明输入框；旧图片说明仅作为兼容资料保留，不转换为正文。

后续接入时，Console 只编辑模板已有的内容位置。新增、删除、类型、顺序和布局仍由展示结构决定。文字副本只复制正文，原图片及替换图片的草稿留在原文档。

同步入口默认折叠。当前未连接状态禁用导入和推送，不自动读取游戏状态或拉取内容。待 Building 的展示结构确定，并明确确认接入范围后，再连接内容来源；发出的请求仍需核对真实回执，结果不明确时只核对，不重送。

验收仅使用独立人工示例，可选一至两张示例图片。交互合同已通过；当前游戏内容接入和真实写回不属于本轮交付结果。
