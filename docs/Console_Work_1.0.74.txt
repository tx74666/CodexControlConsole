Codex Console 1.0.74：限定工作区文件修改

正式 1.0.73 的独立 Work 已取得真实 gpt-6-astra/high 回答并保存到原记录，但原生 Windows 文件工具要求磁碟根读取权限，实际未修改 probe.txt。原失败与已发送意图保留，不重发旧消息。
