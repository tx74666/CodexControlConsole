# Sentence timing

Open a song's lyrics and click **LRC points**. Existing timestamps appear immediately; no Insert tap or analysis run is needed. Blue points are sentence starts and red points are ends. The two rows keep a shared start/end easy to select. The default view spans **10 seconds**; use the previous/next window, 5/10/20-second zoom, or Full song. Follow keeps the visible window near playback; dragging or navigating holds the window for fine editing. Double-click empty timeline space to seek.

Drag a point to preview the whole sentence's new timing. Arrow keys move the selected point by 10 ms; Shift moves by 100 ms. Only a truly shared boundary moves both the previous end and next start; separate acoustic rests remain separate. Crossing an adjacent boundary or introducing a new reversed/out-of-range interval is rejected. Unrelated pre-existing malformed captions do not prevent repairing a different point.

**Save** writes only the changed sentence points for this song and lyric language. **Undo** reverses the last drag/edit; **Cancel edits** restores this song's original timing without a server write. Unsaved drafts survive reload and song/language switches. Other songs' drafts, original lyric text, word timing, acoustic detail and existing manual marks are retained. A changed lyric source is not silently matched onto an older draft: cancel that retained draft explicitly before making a new correction.

Point labels/tooltips distinguish existing manual and acoustic endpoints from LRC timestamps. LRC mainly supplies starts. An end inferred from the next caption, a rest row, track duration or an older estimate is labelled as derived; it is not presented as a measured vocal ending. Merely displaying the timeline never converts LRC or analysis points into manual marks. Save errors retain the draft and original compare-and-set value. Unclear replies are checked with a read-only marks request; unverified results remain pending. A late reply for another song/language cannot replace the active analysis. Save does not flush other pending Insert or word edits.

For a fresh recording, **Insert still marks sentence ends directly**: no first-onset tap is needed. The first missing manual onset is zero; an existing onset is preserved. Each end applies immediately and advances to the next non-empty lyric line while its save runs in the background. At the final end the marking cursor finishes. This direct marking flow is separate from drag previews; a related unsaved drag must be saved/cancelled before Insert can replace that boundary. There is no extra Apply step. Precise timestamp entry is kept in Exact edit and previews a draft for Save.

Playback lights the whole current lyric line together. Playback, pause and seeking do not reorder lyrics or retarget the Insert cursor. Keys inside inputs, IME composition, repeated keydown and modified shortcuts do not create points. Local journal/save failures preserve the captured points and target so retry does not mark twice.

Synthetic controller, DOM-event and persistence tests verify these operations. They do not establish the audible alignment of an unmarked song; listen before treating a derived boundary as a correct vocal end.
