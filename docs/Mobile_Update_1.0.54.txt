Codex Console 1.0.54 · 未归类想法可直接保存

实际问题
在没有配置或授权电脑项目的手机入口，首次“只保存”会报“项目尚未在电脑授权”，把尚未成熟的想法挡在执行授权之前。完整路径还暴露了续聊草稿恢复的问题：电脑已同步的内容仍在，但页面启动生成的空白本机副本盖住了它。此前编辑、版本冲突与图片保护的分段验收没有覆盖这个首次完整路径。

本次修复
- 当前讨论、草稿、附件、只保存、清空和找回可以在“未归类”使用；不要求先选 Workspace，不创建虚构项目或执行权限。
- 已配置项目的分类资料不要求其执行目录仍然存在；未主动选择项目的新想法继续为未归类。
- 手机普通文字 Chat 不再依赖执行项目目录。只冻结当前记录、选定内容和真实来源版本；项目引用、其它记录和不支持的图片传送仍拒绝。
- 一次确认仍只创建一次请求；清空建立新的讨论身份，原讨论迟到答案继续回原记录。
- 重载恢复续聊草稿时，启动产生的空白视图不再当成用户编辑。实际输入、主动清空和等待回执期间继续输入的本机内容仍保留。
- Work 仍必须核对实际项目、明确授权的工作区绑定和允许范围。保存成功不授予执行权限。

验证边界
后端新增首次空项目、失效目录、实际图片恢复、清空找回、重复确认、迟到回答及未授权引用拒绝的隔离行为检查。手机宽度真实浏览器与 HTTP/SQLite 的完整生命周期证据、共享质量检查及正式更新资料核验另存本轮交付记录；浏览器隔离验收不是 iPhone 真机。

仍待接通
普通 Chat 常驻事件转发、实际三档回执与 Codex Work 常驻 App 发送回收入口仍待完成，不能把入队或保存称为真实往返。浏览器扩展的授权答复与真人权限操作仍待收到；没有恢复 heartbeat、调用模型 API 或代换 Cloud Work。

保留原资料、正式安装身份和 Document 根。正式发布后由本机已有更新器自动完成下载校验与安装，不要求用户手动下载安装。
