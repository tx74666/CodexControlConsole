Codex Console 1.0.57 · 普通 Chat 的完成证据与旧队列隔离（2026-10-05）

本版沿用已核实的 Edge 普通新 Chat、Instant／none、准确消息来源和中文“回答已完成”证据。生成停止控件没有现场证据时，契约明确保存 stop=null，回执也必须 stopPresent=null；未知不能写成“不存在”。只有本次提交后出现唯一明确完成状态、完整冻结输入及唯一同源回答，才允许回收；已核实的停止控件仍必须确实不存在。重复完成状态、来源变化、档位变化或旧状态均不能代替结束证据。

首次接通只采用真人批准和实际页面契约观测之后确认的请求。此前未认领的积压请求原样保留，既不自动发送，也不挡住新确认消息。重启仍依据同一冻结契约和持久单次发送账本恢复；送达不明不重送。配置前、更新前仍须检查正在执行和待核对请求。

Console 自有扩展和官方 ChatGPT 浏览器控制扩展用途不同。正式安装更新后，需要真人在扩展页重载 Console 自有扩展，再从其弹窗核对本机配置并启用；安装、重载、权限与启用按钮遵循人机接管规则。Chrome／Edge 注册路径保持原安装身份，用户数据保留。

实际自动往返验收消息为本轮新确认的“你好，请详细介绍你能做什么。”；只有真实新 Chat 回答自动回到原 Console 任务 Output，才能标记这条链路通过。源码、隔离测试、注册、配置和连接分别记录，不代替实际验收。本版目前仅支持纯文字和已核实 Instant 的极速档位；高／Pro、Work 和 iPhone 实机验收仍须分别完成。没有模型 API、API key 或定时派发。
