Codex Console 1.0.59 · 扩展 0.1.2、手机未发送请求与真实 Instant 发送可行性（2026-10-06）

本轮修复范围

真实 Edge 的 Instant 页面曾在完整文字已经写入后，发送按钮仍未就绪。Console 应保留原请求和真实失败原因，不能把编辑器出现文字、扩展就绪或任务入队当成已发送。本轮聚焦输入后的实际发送就绪、带请求身份与阶段的失败回执，以及原生接收端退役已经在 Console 正常终止的旧测试。

发送前必须核对完整冻结输入、普通新 Chat 与实际 Instant 档位，并等待真实发送控件可用后才允许唯一一次点击。档位、输入、页面身份或就绪检查失败时停止；原生端与扩展的持久单次发送账本继续保护该请求。已有 send intent 或送达不明不能改称明确未发送，也不能自动重发。

终止旧测试时保留原消息、失败原因、请求与 attempt tombstone，只结束已终止测试的处理权。原两条历史 pending 不发送、不领取、不清空；新的已确认消息继续使用独立身份。迟到的旧测试回执不能取得新任务的发送权或覆盖另一讨论。

2026-10-06 的手机截图实际阻塞来自当前讨论的一条历史未领取 pending；页面把所有 pending 都显示为自动转发未接通，也不能据此断定浏览器断线。增加严格的“结束这条未发送请求”：只在当前手机、讨论、记录与版本相符，原请求没有领取、发送意图或回答证据，原 job 仍等待时，通过正常事务结束这唯一请求。已开始发送或送达不明仍须核对。原文字、图片、草稿、档位、讨论身份及其他历史请求保留；取消资格由服务端明确投影并在执行时重新核对。更新数据验证完成后才能结束这条已核实的旧请求。

同日真实 Edge 按钮已观察到中文“思考强度即时”及 data-selected-reasoning-effort=none；严格标签校验兼容此精确现场文本，保留 Instant 的逻辑档位与原始 DOM 标签，不将高或 Pro 降档。现有批准、原 DOM 合同和权限范围不改写。

范围与验收

用户选择先确认真实发送与回答能否自动回到同一任务的 Output。本轮不修返回界面，也不替换成定时派发、模型 API、API key、Work 或 Cloud。扩展权限、固定扩展 ID、原生 host 身份及既有浏览器授权范围沿用原配置。

1.0.58 正式安装、官方 ZIP 和扩展 0.1.1 的逐文件一致性已有独立证据。本轮版本号、源码修复与隔离检查不代表 1.0.59 已发布、已安装或真实 ChatGPT 往返已完成。验收须使用明确确认的新请求，核对普通新 Chat 的真实发送、原输入归属、明确回答结束，以及完整回答回到同一 Console 任务；三档、Work 和 iPhone 实机仍须各自验收。

更新时继续沿用正式安装身分与使用者资料，保存任务、草稿、消息、互传、手机配对、音乐、文档、授权文件与设置的原始字节。准备新的完整备份和一次性更新证据；历史已终止 attempt 与测试 intent 保留，不使用“零历史 attempt”作为更新前提。只有存在实际在途工作、未终止的派发或未终止的转发 attempt 时阻止退役。
