Codex Console 1.0.53 · 手机编辑稿与执行选图保护

本轮继续完整手机更新目标，不把普通 Chat 或 Codex Work 入队称为已接通。

手机标题、正文和执行稿的保存以点击时的内容与来源版本为准。保存等待期间继续输入，晚到回执只确认已提交内容，新输入保留为本机草稿。刷新或重载后，旧编辑稿遇到电脑已修改的来源，保留草稿并要求核对当前版本，不能借新的版本号覆盖新内容。

Work 最终审核校验已选原图与新图片的合计数量和大小；超限保留选图和草稿，不能静默截掉已审核的图片。电脑明确拒绝且未入队的容量错误允许保留完整审核上下文后重新审核；送达不明仍保留原请求编号，不自动重发。

长期要点沿用已接受的单条 20000 字与最多 100 条边界，贯通保存、合并、手机副本和完整想法交接。自动补充达到 100 条时，完整回答与来源仍保存，不生成第 101 条要点；整体想法包和 Work 上下文上限继续生效。

手机自动标题按 Unicode 字符截取，避免截断 emoji 后无法交接。文字长度与完整想法包的 UTF-8 字节容量分别核验，整体容量超限如实拒绝，不截断正文或改写建议类型。

隔离实际页面已验证正文及执行稿保存时继续输入、刷新恢复、旧草稿与电脑新版本同时可见及明确核对后保存；测试全过程没有生产修改、模型调用或派工。原图加新图超额、長要点保存后合并与交接、要点满额后完整回答保留、emoji 标题交接另有行为回归。正式安装、来源和原数据保留另以本轮真实发布及更新后验为准，隔离页面不代表 iPhone 真机已验收。

仍待验收：自有 Chrome 转发权限与实际页面能力、普通 Chat 常驻事件回答往返、高／Pro 的真实设置、iPhone 真机键盘与语音。Codex Work 的冻结与文件核验已实现，常驻 App 发送及回答回收入口尚缺；不能用 Chrome 权限、模型 API、定时 heartbeat 或方案报告替代。
