# Microsoft Store 商品信息：简体中文

## 产品名称

Codex Console

## 简短说明

集中管理音乐、桌布、桌面布局、创作工具、软件更新与项目协作的本地 Windows 中控平台。

## 说明

Codex Console 将常用的创作与桌面工作流程集中在一个清晰的 Windows 应用中。你可以导入并整理本地音乐，管理桌布资源，保存仅属于当前设备的桌面布局，并导航 Blender 项目与 GitHub 协作仓库。

个人布局和工作区配置保存在本机。同步内置媒体时只补充缺失内容，不会删除已有文件。可选的问题回报支持文字和用户主动选择的多张截图，并设有明确的每日限额和私有存储。

Codex Console 是独立工具，与 Microsoft、GitHub、Blender Foundation、Valve 或 OpenAI 没有关联或官方合作关系。

## 产品功能

- 仅从本地文件导入并保持分类和排序的音乐库
- 桌布资源与内置媒体增量恢复
- 每台设备独立保存的桌面布局方案
- Blender 项目和 GitHub 协作导航
- 最多附带四张截图的问题回报
- 由 Microsoft Store 管理安装与更新
