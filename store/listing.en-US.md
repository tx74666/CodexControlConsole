# Microsoft Store listing: English (United States)

## Product name

Codex Console

## Short description

A local Windows control center for music, desktop resources, creative tools, updates, and project collaboration.

## Description

Codex Console brings frequently used creative and desktop workflows into one focused Windows app. Organize and play your local music library, manage wallpaper resources, preserve device-local desktop layouts, and navigate Blender projects and shared GitHub repositories.

Your personal layout and workspace configuration stay on your device. Built-in media can be restored additively without deleting files you already have. Optional feedback reports support text and selected screenshots, with clear daily limits and private storage.

Codex Console is an independent utility and is not affiliated with Microsoft, GitHub, Blender Foundation, Valve, or OpenAI.

## Product features

- Local-file music library with persistent ordering
- Wallpaper library and additive built-in media restore
- Device-local desktop layout plans
- Blender project and GitHub collaboration navigation
- Optional issue reports with up to four screenshots
- Microsoft Store managed installation and updates
